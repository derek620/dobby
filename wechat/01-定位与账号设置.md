# 01 定位与账号设置

## 1. 定位

**写给谁**：30~50 岁、不懂技术、但不想被时代落下的普通人——上班族、宝妈、小老板、体制内、临近退休的父母辈。

**不写给谁**：程序员、AI 从业者。他们不缺内容，而且挑剔、不转发。

**人设**：「35 岁程序员老 X」——懂技术，但站在普通人这边说话。不装专家，像一个会修电脑的朋友。

> 人设金句（可以反复用）：**"我敲了十几年代码，现在想把它变成你也能用的东西。"**

## 2. 账号资料修改建议

截图里当前的资料和建议改法：

| 项目 | 现在 | 建议 | 说明 |
|---|---|---|---|
| 名称 | 今晚不敲代码 | **保留** | 有记忆点、有反差（程序员不敲代码 → 那干嘛？用 AI）。改名机会少，不要浪费 |
| 公众号ID | xiao_question | 保留 | 别人基本不会搜 ID |
| 简介 | 35岁程序员，给自己的生活找个Plan B | **35岁程序员，用大白话带你把AI用起来。关注回复「AI」领《普通人AI上手手册》** | 简介要说清"关注你能得到什么"，并把福利钩子放进去 |
| 头像 | Plan B 字母 | 先保留，后期换成真人卡通头像 | 真人感能明显提升信任和关注率 |
| 视频号 | 未绑定 | **绑定**（可以先不发视频） | 绑定后公众号主页多一个入口，视频号以后也能做 |
| 个人认证 | 未认证 | 有空做一下 | 可信度加分，不影响起步 |

## 3. 必须立刻设置的三样东西

### 3.1 被关注自动回复（最重要）

后台 → 内容与互动 → 自动回复 → 被关注回复：

```
你好呀，我是老X，一个敲了十几年代码的35岁程序员👋

这里不讲高深技术，只讲【普通人怎么把AI用起来】。

🎁 回复「AI」，领取《普通人AI上手手册》
📖 回复「入门」，看我写的新手必读3篇
💬 有什么AI问题直接留言，我挑着回复

今晚不敲代码，咱们聊点有用的。
```

### 3.2 关键词自动回复

| 关键词 | 回复内容 |
|---|---|
| AI / 手册 / 资料 | 手册链接（见 `lead-magnet/`，先发成一篇公众号文章或腾讯文档） |
| 入门 | 3 篇入门文章的链接 |
| 提示词 | 提示词模板合集文章链接 |
| 进群 | （500 粉之后再开）个人微信二维码 |

### 3.3 自定义菜单

- **新手必看** → 入门文章合集
- **工具推荐** → 工具合集文章
- **领福利** → 手册

## 4. 每篇文章固定的结尾（引导关注）

```
—— 我是老X，35岁程序员，
用大白话带你把AI用起来。

觉得有用，点个「关注」，下篇不迷路；
转给家里那个还不会用AI的人，比什么都强。

🎁 关注后回复「AI」，领《普通人AI上手手册》
```

> 原理：**"转给家人"**是这个定位最强的传播钩子。大家自己不一定转，但"教爸妈用 AI"的转发意愿非常高。
